Runs every program in `MAKEFUN_INPUT_DIR` on the VM from the kit's `ISA.md` and writes each answer (`stdout.bin` + `exit.txt`) to `MAKEFUN_OUTPUT_DIR`.

Run: `MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts`
